# Contributing

Open an issue with the behaviour you expect, the current result, and relevant OS/Xcode versions. Remove personal data, tokens, and signing identifiers from logs and screenshots.

Keep changes focused. Use native platform conventions, semantic text styles, useful accessibility labels, and explicit error states. Add regression coverage when changing persistence, authorization, validation, or file operations. Run core tests and the affected native workflow before opening a pull request.

Use Conventional Commits, such as `fix: preserve queued messages on reconnect` or `feat: add a filter`. Keep credentials and signing settings local. The repository’s MIT license applies to contributions.
